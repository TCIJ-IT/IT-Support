V44 — خصوصية الصلاحيات والبيانات

مبنية على V43.

التعديلات:
- في اختيار منفذي البلاغ:
  - الأدمن فقط يرى username والصلاحية.
  - IT و IT Manager يرون أسماء المنفذين فقط.
- للأدمن تظهر الصلاحيات بهذا الشكل:
  مدير النظام Admin
  مدير تقنية المعلومات IT Manager
  فريق تقنية المعلومات IT
- ترتيب المنفذين حسب الصلاحية ثم الاسم.
- إدارة المستخدمين صارت للـ Admin فقط.
- غير الأدمن لا يرى صفحة إدارة المستخدمين ولا كلمات المرور ولا usernames ولا الصلاحيات.
- تحديث كاش Service Worker إلى V44.

هذه نسخة مناسبة للمراجعة قبل الاعتماد الرسمي.
