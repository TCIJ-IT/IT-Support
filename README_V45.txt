V45 — إصلاح إشعارات IT وترتيب قائمة المنفذين

مبنية على V44.

التعديلات:
- إصلاح مشكلة حساب IT: عند الضغط على الإشعارات يفتح صفحة الإشعارات ولا يرجع للإحصائيات.
- إخفاء السجل اليومي من حسابات IT.
- حساب IT يظهر له فقط:
  الإحصائيات
  المهام والبلاغات
  متابعة بلاغ
  الإشعارات
  خروج
- قائمة اختيار المنفذين أصبحت بالطول وليس بالعرض، مناسبة لأكثر من 10 حسابات.
- غير الأدمن يرى أسماء المنفذين فقط.
- الأدمن يرى الاسم + username + الصلاحية.
- تسمية الصلاحيات للأدمن:
  مدير النظام Admin
  مدير تقنية المعلومات IT Manager
  فريق تقنية المعلومات IT
- ترتيب المنفذين:
  Admin ثم IT Manager ثم IT.
- تحديث كاش Service Worker إلى V45.
