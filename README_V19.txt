V19 — Mobile Stable + Push Ready

التغييرات:
1) أزيل شريط التنقل السفلي المكوّن من 5 أزرار على الجوال.
2) أصبح هناك زر واحد فقط «المزيد» أسفل اليسار ويفتح نفس القائمة الجانبية.
3) نافذة إكمال البلاغ على الجوال أصبحت Full Screen، والجزء الأوسط فقط هو الذي يمرّر.
4) زر «حفظ التقرير وإغلاق البلاغ» يبقى واضحاً دائماً.
5) يتم ضغط صورة الإكمال بمجرد اختيارها لتخفيف التجمّد وقت الحفظ.
6) مهلة رفع الصورة 15 ثانية حتى لا يبقى التطبيق عالقاً بسبب اتصال ضعيف.
7) أثناء فتح أي Modal تتوقف إعادة رسم Dashboard والجداول في الخلفية.
8) أضيف تجهيز Firebase Cloud Messaging / Web Push:
   - Public VAPID Key يمكن للمدير إدخاله من مركز الإشعارات.
   - كل جهاز يسجل token في it_push_devices.
   - مجلد push-backend-example يحتوي مثال Cloud Function للإرسال التلقائي.

مهم للـ iPhone:
- أضف الموقع إلى Home Screen وافتحه من الأيقونة.
- بعدها افتح مركز الإشعارات واضغط «تفعيل الخلفية».
- تحتاج Public VAPID Key من Firebase Console > Project settings > Cloud Messaging > Web Push certificates.

الإرسال التلقائي والجوال مغلق بالكامل يحتاج نشر Cloud Function أو Backend آمن.
