V31 — ربط الاستبيان الخارجي للمدير

مبنية على V30.

التعديل:
- تم إخفاء نموذج الاستبيان الداخلي لأنه غير مطلوب.
- بقيت طريقة رفع البلاغ من داخل الموقع كما هي.
- بقيت طريقة فتح الاستبيان الخارجي للمستخدمين.
- تم نقل التحكم الإداري إلى السجل اليومي:
  "ربط الاستبيان لرفع البلاغ"
- هذا القسم يظهر للـ Admin فقط.
- يحتوي على:
  فتح الاستبيان
  ربط / تغيير الرابط
  مزامنة الردود
  حالة الرابط الحالي
- زر الربط يحفظ الرابط في:
  it_settings/external_form_url
- زر المزامنة يقرأ الردود من:
  it_external_requests
  ثم يحولها إلى المهام والبلاغات.

مهم:
إذا كان الاستبيان Google Form، فالرابط وحده يفتح النموذج فقط.
حتى تصل الردود للموقع تلقائياً، استخدم ملف:
GOOGLE_FORM_TO_FIREBASE.gs
داخل Google Apps Script واربط Trigger عند إرسال النموذج.
