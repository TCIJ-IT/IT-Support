V40 — نسخة التنظيف النهائية للإشعارات والخلفية

مبنية على V39.

التعديلات:
- حذف اختبار سرعة الإشعارات بالكامل من الواجهة.
- تعطيل دوال اختبار السرعة حتى لا تنشئ أي إشعار أو بلاغ.
- الإشعارات تبقى بشكل بسيط، وتعرض إشعارات اليوم فقط.
- السجل اليومي رجع لشكل V26 البسيط: action + time + details + user/ticket.
- السجل اليومي اليوم فقط ولـ Admin و IT Manager و IT.
- أزرار الإشعارات:
  تفعيل الإشعارات
  تفعيل في الخلفية
  اختبار الصوت
  حفظ الإعدادات
- إضافة حالة مختصرة داخل كرت الإشعارات:
  HTTPS
  Service Worker
  Push
  إذن الإشعارات
  تثبيت التطبيق
  تفعيل الخلفية لهذا الجهاز
  نوع الجهاز
- إخفاء كرت v19PushCard القديم الطويل، لكن استخدام دالة v19EnableBackgroundPush للتفعيل.
- تحديث كاش Service Worker إلى V40.

ملاحظة:
لا يمكن اختبار أجهزة iPhone/Android حقيقية من داخل الحاوية، لكن تم فحص الكود وملفات PWA وJS.
يلزم تجربة فعلية على Android واحد وiPhone واحد قبل الاعتماد الرسمي.
